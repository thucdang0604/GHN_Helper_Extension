📊 Nhập từ Google Sheets

Dán link Google Sheets vào đây — hệ thống tự tải. Sheet cần được chia sẻ "Anyone with the link can view".

Đang tải dữ liệu…
🔒 Sheet chưa share? Làm theo 3 bước này
  1. 1Mở Google Sheets → nhấn nút Share góc trên phải
  2. 2Mục General access → đổi thành Anyone with the link → Viewer
  3. 3Nhấn Copy link → dán vào ô trên → Enter. Xong!
Sheet private / công ty? Tải về máy: File → Download → Microsoft Excel (.xlsx) rồi dùng tab "Excel / CSV".

Kéo thả file PDF vào đây, hoặc bấm để chọn

Hệ thống sẽ cố gắng trích xuất bảng dữ liệu từ PDF. Hoạt động tốt nhất với PDF dạng văn bản (không phải scan).

.PDF
Đang phân tích PDF…
⚠ Lưu ý: Trích xuất bảng từ PDF là xấp xỉ, không đảm bảo 100% chính xác — đặc biệt với PDF được scan hoặc có bố cục phức tạp. Để chắc chắn, hãy xuất dữ liệu từ nguồn gốc sang .xlsx hoặc .csv trước khi nhập vào đây.
Không đọc được file này. Hãy kiểm tra định dạng .xlsx, .xls hoặc .csv rồi thử lại.
